# Purva Silversky landing page concept

Responsive HTML, CSS and JavaScript concept based on the publicly described Purva Silversky residential project.

## Files
- `index.html`: page structure and enquiry modal
- `style.css`: responsive styling, colors, layout and hover states
- `script.js`: mobile navigation, modal behaviour and client-side validation

## Preview
Enable GitHub Pages in **Settings → Pages → Deploy from a branch → main → /(root)**. The page will be served from the repository's GitHub Pages URL.

## Important before publishing
- Images currently use fixed Unsplash image URLs so they can load without a local assets folder. They are illustrative lifestyle photographs, not official Purva Silversky project renders. For a closer project match, replace them with approved project images you have permission to use.
- The enquiry form opens from the fixed right-side **ENQUIRE NOW** tab and all enquiry buttons. It validates Name, 10-digit Indian Mobile Number and Email in the browser.
- **The form does not send or store leads yet.** Connect a form backend such as Formspree or FormSubmit and configure the endpoint in `script.js` before using this page for real enquiries. Do not collect real customer data until the endpoint and privacy notice are ready.
- This is an independent concept page, not the official developer website. Confirm project facts, approvals, prices, availability and legal wording before use.
